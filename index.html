          📱 Auf dem Handy installieren

          1. Offline-Einzeldatei (HTML):
          Die Datei dist/SmartCart_Handy_App.html enthält die komplette App in einer einzigen Datei. Einfach ans Handy senden und im Browser öffnen – funktioniert 100 % offline!
          2. Als App auf den Home-Bildschirm (PWA für Android & iOS):
          • Android (Chrome): Menü (⋮) → „App installieren“ oder „Zum Startbildschirm hinzufügen“.
          • iPhone (Safari): Teilen-Symbol (⬆️) → „Zum Home-Bildschirm“.
          3. Native Android APK / iOS App (Capacitor):
          Über npx cap add android bzw. GitHub Actions wird automatisch eine installierbare Android-.apk gebaut.
